Spin precession: what rotates?

Things to try

  1. Click Start in |+⟩ with B along z. Nothing moves. |+⟩ is an energy eigenstate, the “North Pole” of the rotation.
  2. Set θ to about 50°. Now n̂ circles B. Which probability bar never moves, and why?
  3. Still with B along z, click Start in |+⟩ₓ. P₊ₓ swings between 1 and 0, but P(E₊) stays at 50%. Watch the phase dial.
  4. Switch to B along x and start in |+⟩. Now |+⟩ precesses. Then try |+⟩ₓ, which now sits still. What matters is alignment with B, not which letter the axis has.
  5. Go back to B along z and |+⟩. Pause, then measure Sₓ 50 times with the vector model on. The averages agree, but only one column ever shows just two values.

How to read this picture

What exactly is rotating?

The state is. At every instant the particle is in the “spin-up along n̂(t)” state, and n̂(t) sweeps around B at ω₀. The blue arrow is not a little spinning ball. It marks the one direction along which a Stern–Gerlach measurement would give “up” with certainty. Each point on the sphere labels a state. For spin-½ only, that label happens to be a real direction in the lab: the way you'd have to point the analyzer.

Why doesn't |+⟩ precess in a field along z?

It points along the rotation axis, like the North Pole of a spinning globe. Equivalently, it's an energy eigenstate, so time evolution only multiplies it by an unobservable overall phase. Its azimuth is as meaningless as longitude at the pole.

Why does the teal vector model stick out past the sphere?

Every spin component measures to ±ħ/2, so S² = 3ħ²/4 and the “length” of the spin is √3·ħ/2. But only one component can be definite, so ⟨S⟩ has length just ħ/2. The teal arrows are the classical picture that reproduces both ⟨S⟩ and ⟨S²⟩. It fails because real outcomes are only ±ħ/2, not a continuous range, and because the uncertainty is not ignorance of a hidden value.

How does this connect to classical Larmor precession?

Ehrenfest's theorem gives d⟨S⟩/dt = γ⟨S⟩ × B, the classical torque equation. The expectation value precesses exactly as a classical magnetic moment would, at ω₀ = −γB₀. For an electron, γ < 0, so ⟨μ⟩ points opposite to the arrow and precesses about the same axis.

A 4π surprise

After one period T = 2π/ω₀, n̂ is back where it started, but the state has picked up an overall factor of −1. The spinor needs 4π of rotation to return. An overall sign can't be seen in a single beam, but it shows up when a precessed beam interferes with an unprecessed one. Neutron interferometry experiments in 1975 measured exactly this.
